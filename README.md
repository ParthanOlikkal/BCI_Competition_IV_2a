**Dataset**: 
This is the BCI Competition IV 2a dataset in .mat format collected from https://bnci-horizon-2020.eu/database/data-sets

**DL Model**:
Attempted EEGNet architecture (DOI: 10.1088/1741-2552/aace8c) on the dataset for 2 class classification. Got 53-58% accuracy for each subject.

**ML Model**:
Attempted SVM on FBCSP (DOI: 10.1109/IJCNN.2008.4634130) on the dataset for 2 class classification. Each 80%+ accuracy for each subject.
